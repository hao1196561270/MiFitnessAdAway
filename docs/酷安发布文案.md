# 🛡️ MiFitnessAdAway — 小米运动健康去广告模块（LSPosed）

> 酷安发布文案 · 直接复制粘贴即可

---

## 📦 模块简介

**小米运动健康（Mi Fitness）去广告 LSPosed 模块**，基于现代 libxposed API 102 开发，适配 LSPosed v2.1.1+（Zygisk 版），模块 APK 仅 29KB，轻量无残留。

**目标版本**：`com.mi.health` 3.58.0（其他版本 hook 点可能偏移，请以 3.58.0 为准）。

---

## ✨ 功能一览

| 广告 | 状态 |
|---|---|
| 开屏广告（图/视频） | ✅ 清除 |
| 首页健康页推广卡片（暑期焕新季/以旧换新等） | ✅ 清除 |
| 设备页推广卡片（REDMI Watch 6 等） | ✅ 清除 |
| 运动页轮播卡片 | ✅ 清除 |
| 运动页运营卡片（训练指标以下的运动团/活动推荐） | ✅ 清除 + 禁用多余滚动 |
| 我的页 VIP 会员卡（立即开通） | ✅ 清除 |
| 我的页健康问诊卡 | ✅ 清除 |

**亮点**：
- 🎛️ **自带设置界面**（桌面图标打开）：11 个开关，每类广告可单独控制，跟随系统深浅色
- 🚫 **反 hook 检测**：拦截 App 的 Xposed/Substrate 探测（SensorHelper）
- 🔄 设置修改后**重启应用生效**即可
- 📉 无第三方 SDK、无残留、纯 hook 方案

---

## 🧠 实现原理（感兴趣可看）

- **数据层拦截**：banner 接口 / 开屏缓存 / 会员数据 / 问诊数据直接返回空
- **视图层兜底**：「我的」页是 React Native（YRN）渲染，JS 写死的卡片用**视图树逐层上卷**隐藏，后续内容自动上移不留白
- **运动页锚点策略**：「训练指标」以下运营区整体移除并禁用滚动
- 全部 Hook 点均在 GitHub 开源可查

## 📥 下载与安装

**获取方式**：
- GitHub Releases：https://github.com/hao1196561270/MiFitnessAdAway/releases
- （LSPosed 官方模块仓库审核通过后也可在 modules.lsposed.org 搜索 MiFitnessAdAway）

**安装步骤**：
1. 手机已 root（KernelSU / Magisk）+ 安装 **LSPosed v2.1.1+**（Zygisk）
2. 安装模块 APK
3. 打开 LSPosed → 模块 → 启用 **MiFitnessAdAway**（作用域自动包含小米运动健康）
4. 重启手机一次
5. 打开桌面上的模块图标可调整开关
