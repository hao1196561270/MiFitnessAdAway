# MiFitnessAdAway v1.4 · 真机交付包

小米运动健康（`com.mi.health` 3.58.0）去广告 LSPosed 模块（libxposed API 102，适配 LSPosed v2.1.1+ / KernelSU）。

## 📦 交付文件

| 文件 | 说明 |
|---|---|
| `MiFitnessAdAway-v1.4.apk` | 模块本体（含设置页），约 3.2MB |

## ✅ 环境要求（真机）

1. Android 15 或其他版本系统，已 root（**KernelSU** 或 Magisk）
2. 已装 **LSPosed v2.1.1 或更新版本**（Zygisk 版，API ≥ 101）
3. 手机上的小米运动健康版本为 **3.58.0**（其他版本 hook 点可能失效）

## 📲 安装步骤

```powershell
# 1. 安装模块（电脑 adb 或手机文件管理器安装均可）
adb install MiFitnessAdAway-v1.4.apk

# 2. 打开 LSPosed 管理器 → 模块 → 启用 MiFitnessAdAway
#    （staticScope 已内置，作用域自动指向 com.mi.health，无需手动勾选）
#    建议顺手把 LSPosed 的"隐藏自己"相关选项打开

# 3. 重启（LSPosed 提示的重启，或强停小米运动健康）
adb shell am force-stop com.mi.health
```

## 📋 功能明细（v1.4 hook 清单）

| 目标 | hook 点 |
|---|---|
| 首页/设备/公告 banner | `BannerResponseResultV1/V2.getBannerList()` → 空列表 |
| 运动轮播（V1/V2 双入口） | `BannerImpl.getBannerListAsyncV1/V2` → 直接回调空列表 |
| 开屏广告 | `SplashAdPreference.getShowSplashAdItem()` → null |
| VIP 卡数据（入口/优惠/状态） | `MembershipHelperImpl.getPaymentsPromotion/getOperationConfig/getVipInfo` → null |
| VIP 列表行来源开关 | `IWebSyncKt.getSHOW_AIDONG_PAYMENT_ENTRANCE` → false，`set...` no-op |
| VIP 头部卡 LiveData 填充 | `MineV4ViewModel.m519getVipInfo/m518getVipConfig` → no-op |
| VIP 原生卡视图兜底 | `MineVipView.onAttachedToWindow` → GONE |
| 健康问诊卡 | `DoctorDataRequest.getDoctorDataResult` → null + `MineV4ViewModel.getDoctorDataResult` no-op |
| 反 hook 检测 | `SensorHelper.A()/D()` → 0 |

## ⚠️ 已知边界

- 「我的」页是 RN（React Native）渲染，VIP 头部卡在 JS 模板内；数据层已全部断供，若个别样式仍显示空壳卡，反馈后递归下一版处理
- 只针对 3.58.0；App 更新后需同步更新模块
